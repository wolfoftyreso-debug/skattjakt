Skattjakt

Det finns ofta mer att hitta i ett bokslut än man tror.

Ladda upp ditt preliminära eller färdiga bokslut, så letar Skattjakt efter saker som kan vara värda att undersöka — och visar vad varje fynd bygger på.

Regelverket är ännu inte granskat av en kvalificerad rådgivare. Inget fynd visas därför som fastställt. Ta med resultatet till din redovisningskonsult innan du agerar på något av det.
